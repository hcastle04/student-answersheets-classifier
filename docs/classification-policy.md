# Student Answer Classification Policy

## 1. 목적

학생 답안지 PDF의 첫 페이지에서 OCR로 인식한
학생 이름과 학교명을 기준으로 기존 학생 이름별 폴더에 자동 분류한다.

자동 분류가 안전하지 않은 경우에는 강제로 분류하지 않고
보류 또는 신규생 폴더로 이동한다.

---

## 2. 분류 결과

프로그램의 분류 결과는 다음 세 가지를 기본으로 한다.

### CLASSIFIED

기존 학생을 충분히 식별할 수 있어
학생 이름 폴더로 자동 분류할 수 있는 상태.

### REVIEW

자동 분류에 필요한 정보가 부족하거나
OCR 결과가 불확실하여 사용자의 확인이 필요한 상태.

### NEW_STUDENT

학생 정보는 확인되지만 기존 학생 폴더가 존재하지 않는 상태.

---

## 3. 기본 분류 기준

### Case 1. 이름과 학교가 모두 인식됨

- 이름에 해당하는 학생 폴더가 1개
  - 해당 학생 폴더로 분류

- 동일한 이름의 학생이 여러 명
  - 학교명을 추가 비교
  - 학교까지 일치하면 해당 학생 폴더로 분류
  - 학교가 일치하지 않거나 판별 불가하면 REVIEW

---

### Case 2. 이름만 인식됨

- 동일 이름 학생이 1명
  - 해당 학생 폴더로 분류

- 동일 이름 학생이 여러 명
  - 학교 정보가 없으므로 REVIEW

---

### Case 3. 학교만 인식됨

학생 개인을 특정할 수 없으므로 REVIEW.

---

### Case 4. 이름과 학교 모두 인식 실패

REVIEW.

---

## 4. 신규생 처리

OCR로 이름을 식별할 수 있지만
기존 학생 폴더에서 해당 학생을 찾을 수 없는 경우
NEW_STUDENT로 처리한다.

신규생은 자동으로 학생 폴더를 생성하지 않는다.

사용자가 신규생 여부를 확인한 뒤
학생 폴더를 직접 생성하고 수동 분류한다.

자동 폴더 생성 기능은 추후 개선 가능 기능으로 남긴다.

---

## 5. 반 정보 처리

답안지가 들어 있는 입력 폴더명을 통해
S반, Y반 또는 특강 학교를 판별한다.

### S반

학생 검색 대상:

학생별답안지/S반/

보류 대상:

학생별답안지/S반/보류/

### Y반

학생 검색 대상:

학생별답안지/Y반/

보류 대상:

학생별답안지/Y반/보류/

### 특강

입력 폴더명의 학교명을 기준으로
해당 학교 폴더를 학생 검색 대상으로 사용한다.

예:

- 고려대
- 연세대
- 성균관대

등

보류 대상:

학생별답안지/@@대/보류/

---

## 6. 안전 원칙

프로그램은 오분류보다 보류를 우선한다.

학생을 명확하게 식별할 수 없는 경우에는
임의의 학생 폴더에 분류하지 않는다.

잘못된 자동 분류는 사용자가 발견하기 어렵기 때문에,
불확실한 결과는 REVIEW로 보내는 것을 기본 원칙으로 한다.

---

## 7. 추후 결정할 항목

다음 항목은 OCR 테스트 결과를 기반으로 추후 결정한다.

- 이름 OCR confidence 기준
- 학교 OCR confidence 기준
- 자동 분류 threshold
- REVIEW threshold
- 문자열 유사도 기준
- JEV 적용 여부 및 적용 위치
