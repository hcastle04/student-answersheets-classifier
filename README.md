# Student Answer Classifier

기존에는 매주 약 150명 규모의 학생 답안지 PDF를 하나씩 열어 이름을 확인하고, 각 학생의 개인 폴더로 이동시키는 작업을 수작업으로 진행해 왔습니다. 이 작업은 100명 기준으로 최소 35분이 소요되는 단순 반복 작업입니다.

## Problem

학생별로 분할된 PDF 답안지를 직접 확인하고 학생 이름별 폴더로 이동하는 작업에 많은 시간이 소요됩니다.

1. 업무량 폭증: 수능이 다가오면서 학원에 대학별 특강이 다수 개설되었습니다. 신규 수강생 유입은 물론, 한 학생이 여러 학교의 특강을 교차로 듣는 경우가 많아지면서 분류해야 할 답안지의 물리적인 양이 기하급수적으로 증가했습니다.

2. 작업 흐름의 단절 (Context Switching): 학원 업무 특성상 답안지 분류 중에도 수시로 다른 행정 처리나 추가 작업이 들어옵니다. '분류 작업 → 타 업무 처리 → 다시 분류 작업'으로 이어지는 잦은 업무 단절은 작업 속도를 심각하게 저하시키는 원인이 되었습니다.

## Solution

반복적인 분류 작업을 Python으로 자동화하여 업무 병목 현상을 해소하고, 남는 시간을 활용해 조교로서의 전체적인 업무 수행 능력을 향상시킵니다. 답안지 첫 페이지 정해진 위치에 손글씨로 작성된 '이름'과 '학교명'을 OCR로 인식해 자동으로 해당 학생 폴더로 할당합니다.

## Goal

- PDF 자동 분류: OCR 인식 결과를 바탕으로 학생별 지정 폴더로 PDF 파일 자동 이동
- 예외 및 보류 처리: 손글씨 인식률이 낮거나 결과가 불확실한 경우, 별도의 '보류' 폴더로 이동시켜 데이터 유실 및 오분류 방지
- 신규생 탐지: 기존 디렉토리에 없는 새로운 학생 이름이 인식될 경우 신규 학생으로 탐지
- 동명이인 구분: 이름이 같더라도 답안지에 적힌 '학교 정보'를 교차 검증하여 정확하게 개별 학생으로 구분
- 업무 효율성 측정: 실제 조교 업무 프로세스에 적용하여 단축된 작업 시간(Time-saved) 측정 및 효과 입증
- 정확도 개선: 오분류 사례를 수집하고 분석하여 지속적인 인식/분류 로직 고도화

## Tech Stack

- Language: Python
- Core: PyPDF2, os, shutil (PDF 제어 및 로컬 파일/폴더 라우팅)
- API: CLOVA OCR Template API
- Version Control: Git, GitHub
